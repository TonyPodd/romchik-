# Mafia AI - Быстрый запуск для предзащиты

## Требования
- Python 3.10+
- Node.js 18+
- Веб-камера
- macOS (оптимизировано для Apple Silicon)

## Опции запуска

### Вариант 1: Встроенное распознавание (быстрый старт)
Используется встроенная система ArcFace ONNX. Быстро, но менее точно.

### Вариант 2: CompreFace (рекомендуется для предзащиты!)
Профессиональная система распознавания лиц с точностью 99%+. Требует Docker.

**Почему CompreFace?**
- ✅ Гораздо выше точность (99%+ vs ~80-85%)
- ✅ Стабильное распознавание при поворотах головы
- ✅ Нет путаницы между разными людьми
- ✅ Проверенное производственное решение

**См. подробную инструкцию:** [COMPREFACE_SETUP.md](COMPREFACE_SETUP.md)

## Запуск за 5 минут (встроенное распознавание)

### 1. Backend (Python/FastAPI)

```bash
cd mafia-ai/backend

# Установка зависимостей (если еще не установлено)
pip install -r requirements.txt

# Запуск сервера
uvicorn app:app --reload --host 0.0.0.0 --port 8000
```

Сервер запустится на http://localhost:8000

### 2. Frontend (React/Vite)

```bash
cd mafia-ai/frontend

# Установка зависимостей (если еще не установлено)
npm install

# Запуск фронтенда
npm run dev
```

Интерфейс откроется на http://localhost:5173

## Демонстрация функционала

### Этап 1: Приветствие
- Нажмите "Начать"
- Примите соглашение

### Этап 2: Калибровка стола
- Система автоматически запустит камеру
- Нажмите "Автодетекция" для определения контура стола
- Или нарисуйте контур вручную
- Нажмите "Продолжить"

### Этап 3: Регистрация игроков
- Нажмите "+ Добавить игрока"
- **Новое!** Максимальная точность: 24 образца с полным покрытием ракурсов
- Следуйте подсказкам на экране:
  - "Смотрите прямо в камеру" (6 образцов фронтально)
  - "Поверните голову влево/вправо" (по 4 образца с каждой стороны)
  - "Поднимите/опустите голову" (по 3 образца вверх/вниз)
- Система автоматически захватит образцы с разных ракурсов
- **Улучшение:** Более строгий порог качества + outlier filtering = меньше ложных совпадений
- Введите имя игрока
- Нажмите "Готово"

### Этап 4: Игра
- **Демо детекции:**
  - Распознавание лиц игроков в реальном времени (30 FPS)
  - **Точные прямоугольники** вокруг лиц обновляются каждый кадр
  - Детекция жестов (показывайте пальцы, кулак на столе)
  - Система показывает кому принадлежит рука

## Ключевые улучшения (последний коммит)

### 🎯 Революционная система трекинга лиц

### Отзывчивость и точность
- ✅ **Детекция лиц каждый кадр** - прямоугольники обновляются мгновенно (было: 1 раз в 10 кадров)
- ✅ **FPS 30** - максимально плавная отрисовка (было: 24)
- ✅ **JPEG качество 75** - четкая картинка (было: 60)
- ✅ **Система трекинга лиц** - стабильная идентификация через кадры (было: каждый кадр независимо)
- ✅ **One-to-one mapping** - каждый игрок получает уникальный трек (было: дубликаты имен)
- ✅ **Temporal voting** - голосование по истории для стабильности (было: нестабильные ID)
- ✅ Threshold: 0.40 (стабильность обеспечивается трекингом, не высоким порогом)

### Качество энролла
- ✅ **24 образца** вместо 12 для полного покрытия ракурсов
- ✅ Строгие требования: 6 фронтальных, по 4 влево/вправо, по 3 вверх/вниз
- ✅ Минимум 10 образцов для финиша (было: 5)
- ✅ Улучшенный outlier filtering (порог: 12 образцов)
- ✅ Регистрация ~30-40 секунд, но максимальная точность

## Возможные проблемы и решения

### Камера не запускается
```bash
# Проверьте доступ к камере в Настройках macOS
# System Preferences → Security & Privacy → Camera
```

### Ошибка импорта библиотек
```bash
# Переустановите зависимости
pip install --upgrade -r requirements.txt
```

### Медленная работа / высокая нагрузка CPU
- **Это нормально!** Система настроена на максимальную точность (30 FPS, детекция каждый кадр)
- Закройте другие приложения, использующие камеру
- Проверьте что работает только один экземпляр backend
- На MacBook Pro M1/M2 должно работать плавно

## Архитектура (для вопросов на предзащите)

### Backend
- **Framework:** FastAPI (асинхронный, WebSocket)
- **Face Detection:** ArcFace ONNX + MediaPipe
- **Face Tracking:** IoU-based tracker с temporal voting для стабильной идентификации
- **Gesture Detection:** MediaPipe Hands + YOLO
- **Architecture:** Clean Architecture (Domain/Application/Infrastructure)

### Frontend
- **Framework:** React 18 + TypeScript
- **Build:** Vite
- **UI:** Custom Glassmorphism/Cyberpunk дизайн
- **State:** React hooks
- **Communication:** WebSocket для real-time

### AI Models
- **Face Recognition:** ArcFace ResNet100 (512D embeddings)
- **Hands:** MediaPipe Hands (21 landmarks)
- **Table Detection:** OpenCV (Canny edges + Hough lines)
