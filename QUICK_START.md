# Mafia AI - Быстрый запуск для предзащиты

## Требования
- Python 3.10+
- Node.js 18+
- Веб-камера
- macOS (оптимизировано для Apple Silicon)

## Запуск за 5 минут

### 1. Backend (Python/FastAPI)

```bash
cd mafia-ai/backend

# Установка зависимостей (если еще не установлено)
pip install -r requirements.txt

# Запуск сервера
uvicorn app:app --reload --host 0.0.0.0 --port 8000
```

Сервер запустится на http://localhost:8000

### 2. Frontend (React/Vite)

```bash
cd mafia-ai/frontend

# Установка зависимостей (если еще не установлено)
npm install

# Запуск фронтенда
npm run dev
```

Интерфейс откроется на http://localhost:5173

## Демонстрация функционала

### Этап 1: Приветствие
- Нажмите "Начать"
- Примите соглашение

### Этап 2: Калибровка стола
- Система автоматически запустит камеру
- Нажмите "Автодетекция" для определения контура стола
- Или нарисуйте контур вручную
- Нажмите "Продолжить"

### Этап 3: Регистрация игроков
- Нажмите "+ Добавить игрока"
- **Новое!** Процесс ускорен: всего 12 образцов вместо 20
- Следуйте подсказкам на экране:
  - "Смотрите прямо в камеру"
  - "Поверните голову влево/вправо"
  - "Поднимите/опустите голову"
- Система автоматически захватит образцы с разных ракурсов
- **Улучшение:** Более строгий порог качества = меньше ложных совпадений
- Введите имя игрока
- Нажмите "Готово"

### Этап 4: Игра
- **Демо детекции:**
  - Распознавание лиц игроков в реальном времени
  - Детекция жестов (показывайте пальцы, кулак на столе)
  - Система показывает кому принадлежит рука

## Возможные проблемы и решения

### Камера не запускается
```bash
# Проверьте доступ к камере в Настройках macOS
# System Preferences → Security & Privacy → Camera
```

### Ошибка импорта библиотек
```bash
# Переустановите зависимости
pip install --upgrade -r requirements.txt
```

### Медленная работа
- Закройте другие приложения, использующие камеру
- Уменьшите FPS в настройках (уже оптимизировано до 24)
- Проверьте что работает только один экземпляр backend

## Архитектура (для вопросов на предзащите)

### Backend
- **Framework:** FastAPI (асинхронный, WebSocket)
- **Face Detection:** ArcFace ONNX + MediaPipe
- **Gesture Detection:** MediaPipe Hands + YOLO
- **Architecture:** Clean Architecture (Domain/Application/Infrastructure)

### Frontend
- **Framework:** React 18 + TypeScript
- **Build:** Vite
- **UI:** Custom Glassmorphism/Cyberpunk дизайн
- **State:** React hooks
- **Communication:** WebSocket для real-time

### AI Models
- **Face Recognition:** ArcFace ResNet100 (512D embeddings)
- **Hands:** MediaPipe Hands (21 landmarks)
- **Table Detection:** OpenCV (Canny edges + Hough lines)
